# Test Scenarios — Personalized Learning Path Designer (Idea 52)

## Scenario 1 — Exam-deadline student
- **Input:** Learn single-variable calculus for an exam in 8 weeks, 10 hrs/week, weak algebra.
- **Expected:** prerequisite refresh (algebra), week-by-week path, spaced-repetition schedule, practice exams as milestones.
- **Pass:** Backward Design structure; spacing + assessments present.

## Scenario 2 — Time-constrained professional
- **Input:** Data engineering, 5 hrs/week, 6 months.
- **Expected:** modular path fitting time budget; feasibility validated; hands-on projects.
- **Pass:** feasibility checked; modality matches preference.

## Scenario 3 — Career switcher with prerequisites
- **Input:** Marketing → UX, no design background.
- **Expected:** prerequisite-aware sequencing, portfolio milestones, transferable-skill bridge.
- **Pass:** prerequisites mapped; milestones produce portfolio evidence.

## Scenario 4 — Unrealistic goal/time (rescope)
- **Input:** "Become fluent in Japanese in 3 weeks at 2 hrs/week."
- **Expected:** feasibility flag; rescoped realistic objective + honest timeline.
- **Pass:** infeasibility flagged; goal rescoped, not faked.

## Scenario 5 — Child learner (age-appropriate)
- **Input:** 8-year-old learning fractions.
- **Expected:** age-appropriate cognitive load, shorter sessions, concrete-to-abstract sequencing.
- **Pass:** load + session length appropriate; ZPD-aligned.

## Scenario 6 — Offline / degraded mode
- **Input:** any goal with WebSearch unavailable.
- **Expected:** uses SECOND-KNOWLEDGE-BRAIN.md; flags resource-currency limitation.
- **Pass:** offline limitation stated.
