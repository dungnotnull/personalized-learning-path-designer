## Usage Instructions

### For Users
1. Install Claude Code
2. Add this skill to your skills directory
3. Invoke with: "Help me create a personalized learning path for [your goal]"
4. Follow the guided intake process

### For Developers
1. Clone the repository
2. Install dependencies: `pip install -e ".[dev]"`
3. Run tests: `pytest tests/`
4. Review CONTRIBUTING.md before making changes
5. Submit pull requests for enhancements

### For Maintainers
1. Monitor issues and pull requests
2. Run knowledge updater weekly: `python tools/knowledge_updater.py`
3. Keep SECOND-KNOWLEDGE-BRAIN.md current with research
4. Release new versions as needed
